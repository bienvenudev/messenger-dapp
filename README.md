# Messenger DApp

A full-stack decentralized application (DApp) that lets you read and update a message stored on a smart contract deployed on the **Celo Sepolia** (Alfajores) testnet.

Built while following the tutorial: [Full Stack Ethereum and DApp Development — A Comprehensive Guide (2024)](https://dev.to/azeezabidoye/full-stack-ethereum-and-dapp-development-a-comprehensive-guide-2024-4jfd) by [@azeezabidoye](https://dev.to/azeezabidoye).

---

## Tech Stack

| Layer | Tool |
|---|---|
| Smart Contract | Solidity `^0.8.24` |
| Blockchain Dev | Hardhat `^2.22` + `hardhat-deploy` |
| Frontend | React 18 + Vite 5 |
| Web3 Library | ethers.js v6 |
| Network | Celo Sepolia Testnet (chainId: `11142220`) |

---

## Smart Contract

`Messenger.sol` — stores a single string message on-chain with two functions:

- `getMessage()` — returns the current message
- `setMessage(string)` — updates the message

## Getting Started

### 1. Install dependencies

```bash
yarn install
```

### 2. Set up environment variables

Create a `.env` file in the root:

```env
PRIVATE_KEY="your-metamask-private-key"
INFURA_ALFAJORES_URL="https://celo-sepolia.infura.io/v3/your-infura-key"
```

> ⚠️ Never commit `.env` to git. It is already listed in `.gitignore`.

### 3. Compile the contract

```bash
yarn hardhat compile
```

### 4. Deploy to Celo Sepolia

```bash
yarn hardhat deploy --network alfajores
```

### 5. Run the frontend

```bash
yarn dev
```

Open [http://localhost:5173](http://localhost:5173) and connect MetaMask (make sure it's set to Celo Sepolia network).
